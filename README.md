# Project Name : fit-log-plan

### Project Description -----
is a modern and responsive workout library web application built with Next.js and TypeScript. Users can explore different workouts, view workout details, add exercises to their daily plan, and save workouts for later.





## Technologies Used
- **Next.js** - React framework for building the application
- **React** - Building reusable UI components
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Styling and responsive design
- **DaisyUI** - UI components
- **React Context API** - Global state management
- **React Icons** - Icons
- **React Toastify** - Toast notifications

---

## ✨ Key Features

### 1.  Workout Library
### 2. Today's Workout Plan

### 3. Save Workouts


### 4. 🔔 Toast Notifications
The application provides instant notifications when a workout is successfully added or when a duplicate workout is selected.

### 5. 📊 Workout Statistics
Users can see useful statistics for their workout plan, including total workouts, workout duration, and calories burned.
